# 实验室小程序项目规划

> 创智实验室内部协作平台 · 微信小程序
> 定位：**Web 对外展示，小程序对内实用**

## 一、项目定位

| 项 | 说明 |
|---|---|
| 名称 | `cz-miniapp`（创智实验室小程序） |
| 定位 | 实验室**内部协作平台** |
| 形态 | 微信小程序 |
| 与官网关系 | 官网（`czstudio.tech`）对外展示成员/项目/荣誉，小程序对内支撑日常协作 |

## 二、技术架构

- **前端**：Taro 3 + Vue3 + TypeScript + Vite
- **后端**：复用现有 NestJS（`app/server`）+ MySQL，**不新建后端**
- **认证**：JWT，账号密码登录（复用 `POST /api/login`），token 存 Taro Storage
- **请求域名**：`https://czstudio.tech/api`（需在微信后台配置 `request` 合法域名，要求 HTTPS + 已备案）

## 三、分期规划

| 阶段 | 内容 | 后端改动 |
|---|---|---|
| **第一期（MVP）** | 讨论区 + 公告/通知 | 零改动（复用 `/comments`、`/message`） |
| **第二期** | 任务/待办 + 知识库 | 新增 `Task`、`Doc` 模块 |

## 四、第一期详细设计

### 4.1 后端复用映射

| 小程序功能 | 复用接口 | 说明 |
|---|---|---|
| 讨论区帖子列表 | `GET /api/comments?page=&pageSize=&sort=&category=` | 分页/排序/分类全有 |
| 帖子详情 + 回复 | `GET /api/comments/:id` | 已含嵌套 replies |
| 发帖 / 回复 | `POST /api/comments` | `@Auth()`，带 Bearer token |
| 点赞 | `POST /api/comments/:id/like` | 已实现 toggle |
| 公告列表 | `GET /api/message` | 返回全部 |
| 公告详情 | 前端本地渲染，或补 `GET /api/message/:id` | 现有无详情接口 |
| 登录 | `POST /api/login` | email + password |

### 4.2 小程序端页面

```
src/pages/
├── index/           # Tab1 讨论区（帖子列表，支持分类筛选）
├── post/            # 帖子详情 + 回复 + 点赞
├── compose/         # 发帖（标题/分类/tags/内容）
├── notice/          # Tab2 公告列表
├── notice-detail/   # 公告详情
└── me/              # Tab3 我的（登录 / 退出 / 个人信息）
```

TabBar：`讨论区` / `公告` / `我的`

### 4.3 认证流程

1. 首次进入 → 未登录 → 跳 `me` 登录页
2. `POST /api/login`（email + password）→ 存 token 到 Taro Storage
3. 后续请求统一在 http 封装层携带 `Authorization: Bearer <token>`
4. 第一期**不做注册**（成员账号由管理员在官网后台分配，注册需邀请码且属低频）

## 五、第二期数据模型草案（备案）

```prisma
model Task {
  id        Int       @id @default(autoincrement())
  title     String
  content   String    @db.Text
  assignee  Int       // userId
  status    String    // TODO / DOING / DONE
  priority  String    // LOW / NORMAL / HIGH
  dueDate   DateTime?
  createdAt DateTime  @default(now())
  updatedAt DateTime  @updatedAt
}

model Doc {
  id        Int       @id @default(autoincrement())
  title     String
  content   String    @db.Text   // markdown
  category  String
  tags      String
  author    Int       // userId
  createdAt DateTime  @default(now())
  updatedAt DateTime  @updatedAt
}
```

> 知识库第一版建议先做「只读文档库」（发文档 / 浏览 / 搜索），实时协作后置，避免过重。

## 六、开发顺序（第一期）

1. 初始化 Taro + Vue3 项目骨架，配置 TabBar 三页
2. 封装 http 层 + token 管理，登录页打通 `/api/login`
3. 讨论区：列表 → 详情/回复 → 发帖 → 点赞
4. 公告：列表 → 详情（顺带补 `GET /api/message/:id`）
5. 真机联调 + 配置小程序 request 合法域名
